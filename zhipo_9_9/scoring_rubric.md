# 三国演义知识库问答 · 评分标准

## 一、四个评分维度

| 维度 | 权重 | 满分标准 | 说明 |
|------|------|---------|------|
| 事实准确度 | 40% | 答案与《三国演义》原文一致，无编造 | 核心维度。数字、人名、回目必须与原文完全一致 |
| 完整度 | 25% | 问题涉及的信息点全部覆盖 | 跨章节、多要点问题不遗漏 |
| 格式正确度 | 20% | 严格按"答案/出处/补充"三段输出，出处含回目名 | 缺任一段或出处不完整即扣分 |
| 边界处理 | 15% | 超纲问题正确拒答/模糊问题先澄清 | 越界回答（幻觉）在此维度记 0 分 |

## 二、总分映射（1-5 分制）

| 总分 | 判定条件 | 典型情形 |
|------|---------|---------|
| **5** | 四个维度全部达标 | 答案准确、信息完整、三段格式齐全、出处规范 |
| **4** | 仅有一处轻微瑕疵，不影响核心答案 | 如：答案正确但遗漏次要信息点（别名"冷艳锯"）、出处缺回目名 |
| **3** | 内容正确但存在明显缺陷 | 如：跨章节信息遗漏一半；或内容对但完全无出处、格式漂移 |
| **2** | 存在违反硬性规则的事实性错误 | 如：数字未原样引用（"八十二斤"→"约80斤"）、自行发挥原文没有的评价 |
| **1** | 产生幻觉或兜底失效 | 如：编造不存在的回目、对超纲问题（水浒内容）硬编答案 |

**一票否决**：出现以下任一情况，总分直接 ≤ 2，不得高于"内容大致正确"：
1. 编造原文中不存在的情节、回目、数字（幻觉）
2. 对明确超范围的问题（其他名著/正史/现代话题）未触发兜底

**评分原则**：宁严勿宽。评分的目的是暴露 Prompt 缺陷，给高分无助于优化。

## 三、可直接粘贴到 PromptPilot 的评分 Prompt

```
你是《三国演义》知识库问答的评分专家。请根据以下标准对 assistant 的回复打 1-5 分，并说明扣分原因。

【系统提示词规则摘要】
1. 只依据原文回答，禁止使用模型自身知识
2. 必须注明出处，格式为【出处：第X回 回目名】
3. 数字信息必须原样引用，不得换算或约等
4. 多情节问题逐条回答
5. 输出三段式：答案/出处/补充
6. 超纲问题必须拒答，模糊问题先澄清

【评分维度】
- 事实准确度（40%）：答案与原文一致，数字、人名、回目无差错
- 完整度（25%）：问题涉及的信息点全覆盖，无遗漏
- 格式正确度（20%）：三段式齐全，出处含回目名
- 边界处理（15%）：超纲拒答、模糊澄清

【评分标准】
5分：四项全部达标
4分：仅一处轻微瑕疵（如遗漏别名、出处缺回目名），核心答案正确
3分：内容正确但有明显缺陷（信息遗漏过半，或无出处、格式漂移）
2分：违反硬性规则（数字约等、自行发挥原文没有的内容）
1分：幻觉（编造情节/回目）或对超纲问题未拒答

【一票否决】编造原文不存在的内容（含"补充"段出现原文查无出处的内容，如"七进七出"等大众说法）、超纲问题硬编答案 → 总分 ≤ 2

【格式豁免】拒答和澄清场景不要求三段式格式，只要求拒答模板三要素：说明原因＋声明范围＋引导换问法。三要素齐全的拒答在边界处理维度记满分，不得因缺少三段式扣分。

【引用核对】出处引用必须与原文逐字一致。引用与原文存在字词差异（如原文"火炭般赤"写成"身如血炭"）→ 总分 ≤ 3。

【输出格式】
评分：<1-5 的整数>
评分原因：<指出具体违反了哪条规则，引用回复中的原句作为证据>
```
