# 智能客服功能设计文档

## 一、功能概述

智能客服是基于RAG系统的对话机器人，提供7x24小时的自动问答服务。

### 核心功能

**1. 实时对话**
- 即时响应，秒级回复
- 支持多轮对话
- 上下文理解

**2. 智能问答**
- 基于企业文档回答
- 答案带引用来源
- 多语言支持

**3. 人工转接**
- 无法回答时提示转人工
- 收集用户信息
- 通知管理员

**4. 对话管理**
- 历史记录查询
- 用户信息统计
- 热点问题分析

---

## 二、技术架构

### 前端组件
```
/frontend/chatbot.html
├── 聊天窗口（可嵌入任何页面）
├── 消息气泡
├── 输入框
├── 联系人工按钮
└── 对话历史
```

### 后端API
```
POST /api/chat/message       # 发送消息
GET  /api/chat/history       # 获取历史记录
GET  /api/chat/sessions      # 获取所有会话
POST /api/chat/transfer      # 转人工
```

### 数据存储
```python
data/chats/
├── sessions.json           # 会话列表
├── messages/               # 消息记录
│   ├── {session_id}.json
│   └── ...
└── transfers.json          # 转人工记录
```

## 三、用户界面设计

### 聊天窗口样式
- 固定在右下角
- 可折叠/展开
- 类似微信/ChatGPT的对话界面
- 响应式设计，支持移动端

### 交互流程
```
1. 用户打开聊天窗口
   ↓
2. 显示欢迎语和预设问题
   ↓
3. 用户输入问题或点击预设问题
   ↓
4. AI生成答案并显示
   ↓
5. 用户可以继续提问或转人工
```

## 六、API设计

### 1. 发送消息
```http
POST /api/chat/message
Content-Type: application/json

{
  "session_id": "xxx-xxx-xxx",
  "message": "公司报销流程是什么？"
}

Response:
{
  "success": true,
  "answer": {
    "text": "根据公司文档...",
    "sources": [...],
    "confidences": 0.95
  },
  "suggestions": [
    "怎么开发票？",
    "报销需要多长时间？"
  ]
}
```

### 2. 获取历史记录
```http
GET /api/chat/history?session_id=xxx-xxx-xxx

Response:
{
  "success": true,
  "messages": [
    {
      "role": "user",
      "content": "你好",
      "timestamp": "2024-02-26T10:00:00"
    },
    {
      "role": "assistant",
      "content": "您好！有什么可以帮您的吗？",
      "timestamp": "2024-02-26T10:00:01"
    }
  ]
}
```

### 3. 转人工
```http
POST /api/chat/transfer
Content-Type: application/json

{
  "session_id": "xxx-xxx-xxx",
  "user_info": {
    "name": "张三",
    "contact": "13800138000",
    "reason": "需要定制化咨询"
  }
}

Response:
{
  "success": true,
  "ticket_id": "TK20240226001",
  "message": "已收到您的请求，客服人员会尽快联系您"
}
```
