## 录制建议

### 前期准备
1. **准备演示数据**
   - 上传5-10个真实的企业文档
   - 包含：员工手册、产品信息、技术文档
   - 确保问答效果能展示优势

2. **测试系统性能**
   - 确保响应速度够快（<3秒）
   - 检查界面美观度
   - 验证功能完整性

3. **准备录屏环境**
   - 清理桌面，关闭无关应用
   - 使用高清分辨率（1920x1080）
   - 关闭系统通知

### 录制技巧
1. **使用专业工具**
   - Mac：QuickTime Player（免费）、ScreenFlow（付费）
   - Windows：OBS Studio（免费）、Camtasia（付费）

2. **语速和节奏**
   - 语速适中，不要太快
   - 关键信息处停顿
   - 配合画面切换

3. **画面质量**
   - 界面放大到足够清晰
   - 鼠标移动要流畅
   - 打字速度适中，让观众看清楚

4. **声音清晰**
   - 使用外接麦克风
   - 在安静环境录制
   - 后期可以加字幕

### 后期制作
1. **添加背景音乐**（轻快、专业）
2. **添加字幕**（可选，但推荐）
3. **添加转场效果**（简洁为主）
4. **片头片尾**（logo、联系方式）
5. **导出设置**
   - 分辨率：1920x1080
   - 帧率：30fps
   - 格式：MP4
   - 码率：适中（保证清晰度）
