# 银行高净值客户 AI 运营助手

面向银行高净值高价值客户的智能运营系统，集成数据生成、多种机器学习模型和可视化大屏。

## 技术栈

| 类别 | 技术 |
|------|------|
| 大屏框架 | Streamlit |
| 机器学习 | scikit-learn (逻辑回归 / 决策树 / GBDT / 随机森林) |
| 聚类分析 | K-Means, DBSCAN |
| 关联分析 | mlxtend (Apriori) |
| 时间序列 | statsmodels (ARIMA), 移动平均 |
| 可视化 | Plotly, Matplotlib |
| 数据处理 | Pandas, NumPy |

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 生成数据（已预生成，可跳过）
python data/generate_data.py

# 3. 启动大屏
streamlit run app.py
```

## 模块详解

### 1. 合成数据生成 (`data/generate_data.py`)

生成 2000 条模拟银行客户数据，模拟真实财富分布特征：

| 字段 | 说明 |
|------|------|
| 基本信息 | 客户ID、年龄、性别、职业、城市 |
| 资产数据 | AUM、存款、理财、基金、保险、信托 |
| 交易行为 | 月均交易次数、月均交易金额 |
| 客户等级 | 普通 / 银卡 / 金卡 / 白金 / 钻石 |
| 产品持有 | 持有产品列表（用于关联分析） |
| 资产趋势 | 近12个月月度资产（用于时间序列） |
| 标签 | 是否高价值客户（AUM ≥ 500万） |

数据特点：
- 使用对数正态分布模拟真实财富分布（少数人持有大量财富）
- 企业主和高管资产乘以增长系数
- 中年客户（30-60岁）资产更高
- 客户等级按 AUM 阈值自动划分

### 2. 分类模型 (`models/classification.py`)

**目标**：预测客户是否为高价值客户（AUM ≥ 500万）

使用 4 种模型对比：

| 模型 | 特点 |
|------|------|
| 逻辑回归 | 线性模型，可解释性强，需要特征标准化 |
| 决策树 | 非线性模型，可解释性强，容易过拟合 |
| GBDT | 梯度提升集成方法，准确率高 |
| 随机森林 | Bagging 集成方法，鲁棒性好 |

**输出**：各模型的准确率、精确率、召回率、F1 分数对比，ROC 曲线，特征重要性排名。

### 3. 聚类分析 (`models/clustering.py`)

**目标**：对客户进行无监督分群

| 方法 | 说明 |
|------|------|
| K-Means | 通过手肘法和轮廓系数确定最优 K 值，将客户分为 K 个群体 |
| DBSCAN | 基于密度的聚类，能发现任意形状的簇和噪声点 |

聚类特征：AUM、交易频率、交易金额、产品数量、各类资产。

**输出**：PCA 降维散点图、雷达图（各客群特征画像）、客群描述。

典型客群：高净值活跃群、中产成长群、中产稳健群、大众潜力群等。

### 4. 关联分析 (`models/association.py`)

**目标**：发现产品之间的购买关联，实现交叉推荐

使用 **Apriori 算法**从客户产品持有记录中挖掘：
- **频繁项集**：经常被一起购买的产品组合
- **关联规则**：支持度、置信度、提升度三个指标衡量规则强度
- **推荐建议**：基于规则生成"买了 A 推荐买 B"的建议

关键指标：
- **支持度**：产品组合在所有客户中出现的频率
- **置信度**：买了 A 之后买 B 的概率
- **提升度**：买了 A 对买 B 的提升效果（>1 表示正相关）

### 5. 时间序列 (`models/timeseries.py`)

**目标**：预测客户未来 3 个月的资产变动

| 方法 | 说明 |
|------|------|
| 移动平均 | 取最近 N 个月的平均值作为预测，简单直观 |
| ARIMA | 自回归积分滑动平均模型，捕捉趋势和周期性 |

**输出**：历史资产曲线、预测曲线、95% 置信区间、趋势方向和增长率。

## 大屏页面

### 首页 - KPI 概览
客户总数、总 AUM、高价值客户占比、户均 AUM、户均产品数等核心指标卡片，客户等级和职业分布图。

### 📊 数据总览
AUM 分布直方图、客户等级饼图、城市 AUM 排名、职业分布、数据预览表格。

### 👥 客户分群
手肘法和轮廓系数图（选择最优 K）、PCA 聚类散点图、雷达图（客群特征画像）、各客群统计描述。

### 🏆 高价值客户预测
四模型性能对比表、ROC 曲线对比、各模型特征重要性柱状图、指标分组柱状图。

### 📈 资产变动预测
全体客户平均资产趋势、单个客户历史 + 预测对比图（含置信区间）、预测结果汇总表。

### 💎 产品推荐
频繁项集列表、产品共现热力图、关联规则气泡图、推荐建议列表、各产品持有率柱状图。
