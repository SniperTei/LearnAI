### SHAP分析
* 可以用SHAP分析 高价值客户预测
* SHAP (SHapley Additive exPlanations)
  是一种模型可解释性方法，用来解释"模型为什么做出这个预测"。
  核心思想：来自博弈论的 Shapley 值 ——
  把预测结果"公平分配"给每个特征，告诉你每个特征对这次预测贡献了多少。

  举个例子：
  客户C11020 预测为"潜力客户"，概率 98.7%

  特征贡献：
    AUM (466万)         +0.35  ████████████████
    近3月增长率 (+12%)   +0.25  ████████████
    持有产品数 (5个)     +0.15  ███████
    波动率 (低)          +0.10  █████
    年龄 (42)           -0.02  █

  和我们项目里"特征重要性"的区别：

  ┌──────┬──────────────────────────────────┬──────────────────────────────────┐
  │      │            特征重要性            │               SHAP               │
  ├──────┼──────────────────────────────────┼──────────────────────────────────┤
  │ 粒度 │ 全局（整体哪个特征重要）         │ 局部 + 全局（每条预测都能解释）  │
  ├──────┼──────────────────────────────────┼──────────────────────────────────┤
  │ 方向 │ 只知道"重要"，不知道正向还是负向 │ 知道"这个特征让预测变高还是变低" │
  ├──────┼──────────────────────────────────┼──────────────────────────────────┤
  │ 交互 │ 不考虑特征间交互                 │ 能发现特征组合效应               │
  └──────┴──────────────────────────────────┴──────────────────────────────────┘

  简单说：特征重要性告诉你"什么重要"，SHAP 告诉你"为什么重要、怎么影响的"。


### AUM (Assets Under Management) = 资产管理规模，就是客户在银行托管的全部资产总额。

在我们项目里就是每个客户的资产总额，包括存款、理财、基金、保险、信托等的总和。它是区
分客户价值最核心的指标 —— AUM ≥ 500万就标记为"高价值客户"。

### 聚类分析

聚类分析是一种无监督学习方法，把数据按相似度自动分组，不需要事先告诉它"标准答案"。

  通俗理解：你有一堆客户，不知道该怎么分群，算法自动把特征相似的客户聚到一起。

  我们项目里的例子：

  输入：2000个客户的 AUM、交易频率、产品数等特征

  算法自动分出4群：
    高净值活跃群 (160人) → AUM高、交易频繁
    中产成长群   (304人) → AUM中等、增长快
    高净值活跃群 (17人)  → 极高净值
    中产稳健群   (1519人) → AUM中等、交易少

  和分类的区别：

  ┌──────────┬──────────────────────┬────────────────────┐
  │          │         分类         │        聚类        │
  ├──────────┼──────────────────────┼────────────────────┤
  │ 学习方式 │ 有监督（有标签）     │ 无监督（没标签）   │
  ├──────────┼──────────────────────┼────────────────────┤
  │ 目标     │ 预测已知类别         │ 发现未知分组       │
  ├──────────┼──────────────────────┼────────────────────┤
  │ 例子     │ 预测"是否高价值客户" │ 自动把客户分成几群 │
  └──────────┴──────────────────────┴────────────────────┘

  关键问题：分几群合适？ →
  这就是手肘法和轮廓系数解决的问题，在"客户分群"页面有两张图帮你判断最优K值。

#### 聚类分析案例
  高复购，中产家庭，年轻高消费等群组。
  KMeans聚类，KNN分类
  k=3
  class=0， 中心0【s1, s3, s4..】 => 中心0’
  class=1， 中心1[s2, ..] => 中心1‘
  class=2， 中心2[s5, ..] => 中心2‘

  ```
  解释：
  这是 KMeans 聚类的迭代过程，我用人话翻译：

  K=3 是什么？

  K 就是你想分几群。K=3 就是把客户分成 3 群。

  迭代过程（一步步来）

  第1步：随机选3个中心点
  中心0 = 随机位置
  中心1 = 随机位置
  中心2 = 随机位置

  第2步：分配 — 每个客户找离自己最近的中心
  中心0 分到了客户 s1, s3, s4...  → 这就是 class=0
  中心1 分到了客户 s2...           → 这就是 class=1
  中心2 分到了客户 s5...           → 这就是 class=2

  第3步：更新中心 — 算出每群的真实中心
  class=0 里 s1, s3, s4 的平均值 → 新中心0'
  class=1 里 s2... 的平均值       → 新中心1'
  class=2 里 s5... 的平均值       → 新中心2'

  第4步：重复第2-3步，直到中心不再变化 → 收敛，完成

  图解

  初始随机:      第1轮分配:       收敛后:
     ?  ?  ?     ● ● ● ●         ● ● ● ●
                 ↗               ↗
     s1 s2      ○  ○ ●          ○  ○ ●
     s3 s4       ↗               ↗
     s5          ■               ■

    3个随机点   按距离分群       最终稳定分组

  总结：KMeans 就是不断"分组 → 算中心 → 重新分组"的循环，直到稳定。和 KNN 的区别是 KNN
  是分类（有标签），KMeans 是聚类（无标签，自己找分组）。

  ```

### 关联规则

关联规则就是**"买了A的人通常会买B"**的规律。

  通俗例子

  超市发现：买尿布的人经常也买啤酒 → 这就是一条关联规则

  在我们项目里就是：买了"国债+外汇"的客户，有56%的概率也会买"贵金属+存款"

  三个关键指标

  用这条规则举例：买了外汇 → 推荐贵金属

  ┌────────┬────────────────────────────────────────┬───────────────────────────────┐
  │  指标  │                  含义                  │             例子              │
  ├────────┼────────────────────────────────────────┼───────────────────────────────┤
  │ 支持度 │ 多少人同时买了这两个？                 │ 5%的客户同时持有外汇和贵金属  │
  ├────────┼────────────────────────────────────────┼───────────────────────────────┤
  │ 置信度 │ 买了外汇的人中，多大比例也买了贵金属？ │ 56%买了外汇的客户也买了贵金属 │
  ├────────┼────────────────────────────────────────┼───────────────────────────────┤
  │ 提升度 │ 买了外汇是否真的促进买贵金属？         │ 2.25，是正常概率的2.25倍      │
  └────────┴────────────────────────────────────────┴───────────────────────────────┘

  提升度 > 1 = 正相关，说明推荐有效
  提升度 = 1 = 没关系
  提升度 < 1 = 负相关，买了反而不买了

  在项目里的应用

  打开 "💎 产品推荐" 页面，你会看到：

  前提产品: 外汇, 国债
  推荐产品: 贵金属, 存款
  置信度: 56%
  提升度: 2.25

  意思是：当一个客户已经买了外汇和国债，我们有较高信心推荐他贵金属和存款，成功率是随机
  推荐的 2.25 倍。

  实际价值：客户经理看到这个，就知道给客户推荐什么产品成功率最高
