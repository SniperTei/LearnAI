# 08 Customer Skills

> **FDE 的护城河。**
> 技术可以现学，沟通和业务理解是慢慢长出来的。

## 学完应该能回答

- 客户说"我要个 AI 助手"，你 30 分钟能问出什么？
- 怎么向 CFO 解释"为什么这个 AI 项目值 50 万"？
- demo 演示翻车了（AI 答错了），怎么救场？
- 客户提的需求明显不合理，怎么说不？
- 客户内部两个 stakeholder 意见冲突，你怎么处理？

## 实战任务

- [ ] 找一个朋友（非技术），给他讲你的 my_com_rag，记录他的提问
- [ ] 给 my_com_rag 写一份"给客户看的 1 页纸介绍"
- [ ] 录一个 3 分钟 demo 视频
- [ ] 找 1 个真实场景（朋友的创业公司 / 自己的痛点），走完需求澄清 → 方案 → demo
- [ ] 写一篇"我做了 N 次免费咨询后学到的"
