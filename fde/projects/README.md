# Projects — 完整 Case Study 实战

> 把 fde/ 里学到的所有能力，整合到 1–2 个完整项目里。
> 这是简历上最值钱的部分。

---

## 每个项目必须包含

### 1. 项目背景（业务问题，不是技术栈）
- 客户/用户是谁
- 痛点是什么（量化：多少人 / 多少时间 / 多少钱）
- 为什么 AI 是合理的解

### 2. 需求假设文档（1 页纸）
- 用户画像
- 关键场景
- ROI 假设
- **不做什么**（明确划掉）

### 3. 技术方案
- 架构图
- **选型理由**（不是"用了 X"，而是"为什么用 X 不用 Y"）
- Trade-off 列表

### 4. 评估报告
- Golden set（50+ 条）
- 离线指标（RAGAS / LLM-as-Judge）
- 在线指标（用户反馈 / 采纳率）
- 改进对比（v1 → v2 提升在哪）

### 5. 生产化清单
- 可观测性（trace / 成本 / 延迟）
- Guardrails
- 降级方案
- 部署文档

### 6. 复盘博客
- 踩过的坑
- 学到的非技术经验
- 如果重做会怎么改

## 项目模板目录

```
projects/
└── my_project_name/
    ├── README.md              # 1 页纸项目介绍
    ├── docs/
    │   ├── business.md        # 业务问题 + ROI 假设
    │   ├── architecture.md    # 技术方案 + 选型理由
    │   ├── evaluation.md      # 评估报告
    │   └── retrospective.md   # 复盘
    ├── data/
    │   └── golden_set.jsonl   # 评测集
    ├── src/
    └── deploy/
```

## 推荐项目方向

### Level 1（必做）：升级 my_com_rag
- [ ] 把 `ai_learn/my_com_rag/` 改造成符合 FDE 标准的作品级项目
- [ ] 补齐：评估、监控、Guardrails、压测报告、复盘博客
- [ ] **这个项目可以作为你的代表作**

### Level 2（选做）：垂直行业 case study
任选其一：
- [ ] **法律合同审查助手**：合同分段 + 风险条款识别 + 引用追溯
- [ ] **教育个性化辅导**：根据学生错题出讲解 + 追踪进步
- [ ] **企业内部知识助手**：接入 Slack/Notion + 多轮对话 + 引用
- [ ] **客服工单自动回复**：分类 + 起草 + 人工接管
- [ ] **财报分析助手**：Text2SQL + 异常检测 + 可视化

### Level 3（挑战）：开源工具
- [ ] 把某个反复要写的模式（如 eval pipeline / prompt 版本管理）做成开源工具
- [ ] 这是简历加分项，也是接触社区的方式

## 项目完成度自评

每个项目按这个标准打分（1–5）：

| 维度 | 1 分 | 5 分 |
|------|------|------|
| 业务价值清晰度 | "我做了 X" | "这帮客户省了 Y 人时 / 赚了 Z 元" |
| 技术深度 | 能跑 | 能讲清每个选型的 trade-off |
| 评估 | 凭感觉 | 量化指标 + 对比基线 |
| 生产化 | 本地能跑 | 监控 + 降级 + 部署文档齐全 |
| 复盘 | 没有 | 写清楚坑、原因、改进方向 |

**目标**：代表作至少 4 分以上。
